# Not listed as equivalent: the neighbour order (eight cells, then seams ascending) changes no result, since a parent changes only on a
# strictly smaller cost (dispatch N-d); the bridge's "solid" (a walkable bit is always solid, PLATE_NAV_MISMATCH) and "surface passable"
# (a blocked surface already has cost 0, so the cell is not walkable either way); the smallest-cost fallback 1 (only used with no walkable
# node, where every query is Rejected); the heap's initial capacity.
