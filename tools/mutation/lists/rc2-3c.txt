# RC2-3c commander: R5's two ties go to the target CommanderQuota.Plan picked earlier (rankOut), not to the lower point
# index. Each tie back to the lower index, each rank comparison the other way, and the rank source (rank as the index,
# no -1 for a point that is no target, no length check). Around the two rewritten lines: the deficit against the order
# of picking (an earlier target with a smaller deficit; the order alone), the first step's direction (wanting less;
# wanting a different number) and point 0 (not kept as the pick in either step; not returned between the steps). The R5
# entries of rc2-3.txt (steps swapped, each tie to the higher index) stay in that list, on the new text.
#
# Not listed, because the pick is the same: groupsAt[i] == 0 as <= 0 (a count is never negative); in either step the
# tie's == as >= (a larger value is taken by the comparison before it) and the rank's < as <= (two targets never share
# a rank); in the first step the tie's == as <= (CommanderQuota.Plan never gives a target picked earlier a smaller
# wanted count). Not listed either: !blocked[i] dropped from either step, because the tests then never end
# (rc2-3.txt's rc2-3-r5-blocked-not-kept is the entry for that rule).

note = among targets nobody goes to, a tie goes to the lower index again

|
