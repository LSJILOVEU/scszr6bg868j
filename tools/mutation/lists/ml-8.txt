# ML-8: units walk over floor plates (Interim/InterimLocomotion.Vertical.cs and its use in the path, crowd and player movers),
# the plate binding and the terrain branch for plate maps. Filter: ML-8 tests.
# Not listed: SeamInto's lowest-layer choice (plates in one cell are kept apart by the clearance rules, so at most one seam
# lands on a cell); TryEnter's same-cell shortcut (the orthogonal rule gives the same answer for a cell the unit stands on);
# the save and load of the graph digest (one side alone fails with an exception) and its hash line (the content manifest
# already carries plates.nav, the same digest); LayeredRouteCost (AI only; on layer 0 it equals the grid search on these maps);
# PlateSpeedMilli's node-missing fallback (a unit's own cell always has a node on its layer); the player's long-step path
# check (player steps are shorter than the radius, so the end test decides); the binding's foot-anchored mask (no Ml8 world
# has an ML-3 body; BodiesOverlapByTheirVerticalRanges binds it directly); AiFireFeature's pack choice (IsActive already
# reads it with ?.; only a plate map with AI fire rules and no terrain pack differs); Standable's ring limit; the
# ground field's !layered guard in Grounded (Settle and OnLayer set Y on plate worlds after it); Standable's ring-only skip
# (inner cells were already searched by smaller rings, so the first hit is the same).
