# RC1-K4: a stage of the showcase is a map file and one content layer. One route makes the world of every stage: the map
# file baked for the stage's layer, the map file's own recipe with the layer's unit types, the player in team 1's first
# deployed soldier (show-1.txt lists the unit types and the player). The bake can be asked for another layer than the one
# the description names.
# Not listed: the lines of the map files (the soldiers, reserves and points of the house, the hills and the melee field)
# and of the content layers. This tool mutates code only; Show1Tests.AStageStartsWithItsForcesAndThePlayerInTeamOne and
# the tests of each stage hold those lines.

[rc1-k4-bake-ignores-the-layer]
file = Assets/WarCore/Content/MapTools/MapBake.cs
filter = FullyQualifiedName~WarCore.Tests.E1bRecipeTests
expect = WarCore.Tests.E1bRecipeTests.BakingForAnotherLayerKeepsTheDescriptionAndNamesTheLayer
note = the bake names the description's layer whatever layer is asked for
original:
|             return new MapBakeResult(Sha256(canonical), pack ?? desc.Pack, mapBytes, BuildSetup(desc, WcMapReader.Read(mapBytes)));
replacement:
|             return new MapBakeResult(Sha256(canonical), desc.Pack, mapBytes, BuildSetup(desc, WcMapReader.Read(mapBytes)));
