# AI-P5a: AI squads (who follows whom), the squad parts (a member asks as its leader and stands at an offset), their
# saved state, the ai.squad* content fields and the wiring into a battle and its view.
#
# Left out, with the reason:
# - `while (bodies < target)` -> `<=` and `while (target - bodies >= 2)` -> `>= 1`: the same squads, the caps on
#   Recruit already allow nobody.
# - dropping `counts[leader]++` in Recruit: a squad is served once per Form and Count runs on the next Step.
# - `unit.Team < 1` -> `< 0`: Form starts at team 1, a team 0 unit is never free.
# - keeping squads whose leader is gone, or members whose squad is gone, in Clean; dropping `served[best] = true`;
#   dropping `free[pick] = false`: these end in an exception or never return, which the tool reports as invalid, not
#   as killed.
# - dropping the sort in Gather, or reading `foundTeams[i]` / `foundAt[i]` instead of `[from[i]]`: a battle's entity
#   store hands its units out in stable id order already, so the sort moves nothing and no test can tell.
