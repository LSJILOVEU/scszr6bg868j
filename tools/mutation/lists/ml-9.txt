# maps; straight up and down on plate maps; the plates.field content key. Filter: ML-9 tests.
# Not listed, equivalent: the tie rule of LineStop (ground wins at equal t): at an equal t both tests report the same point
# (ATieGivesTheCommonPoint), so "plate wins" returns the same bits. The cross product against comparing the distances of the
# two points: both order the same along one segment up to the points' rounding, and the rounding never reverses two hits more
# than 1 raw apart; no segment was found where they disagree. "Add the key without plates" cannot be written: the key is added
# by the plate feature, which is not on without plates (AWorldWithoutPlatesHasNoFieldKey locks the absence).
