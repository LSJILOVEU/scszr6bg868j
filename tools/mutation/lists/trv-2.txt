# TRV-2: traversal kinds section, LinkDerive (K15), MapGate.Links.
# Filter: the TRV-2 tests (FullyQualifiedName~Trv2).
# Not listed (equivalent, with the reason):
#  - c0 without "highest ground corner of m": a, m, b are in a line, so two corners of m are shared with a and two with b,
#    and plates are never below the ground (PlateSpan rule 3); max(hi(a), hi(b)) is never below it (TRV-2 card A2).
#  - fixed point "top > c" written ">=": a span with top == c leaves c unchanged.
#  - fixed point done in one pass: spans are sorted by bottom, so one pass is the fixed point (trv2-sort-bottom-desc and
#    trv2-fixpoint-strict cover the order and the comparison instead).
#  - edge gap "own plate left out": a plate's span bottom is its lowest corner minus a thickness >= 0.5 m, always below
#    max(hi(a), hi(b)), so it never passes "bottom >= top" anyway.
#  - ticks "at least 1": ticksBase >= 1 is enforced by the reader and the TraversalKind constructor.
#  - seam "<= becomes <" / "one end point only": the seam test lives in LayeredNav (Sim, locked, not this package);
#    LinkDerive asks the graph (trv2-seam-ignored).
#  - "centre of the cell can stand" (T2-21): not added; a walkable cell's centre footprint never reaches another cell.
