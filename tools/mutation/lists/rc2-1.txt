# RC2-1: the player leads a squad. The led squad (Battle/Ai/LedSquad.cs) with its rules and formation, the crowd rule that
# lets the leader through its own members (InterimLocomotion.Crowd.cs, ICrowdPass, CrowdPassFeature), how the battle makes
# it (MatchFeature: only with both rules and a player; the adapter's IsCommanded and TryStandAt), the bridge (BridgeCommand,
# SimSession: the commands, the band, FreeTick), the keys and the HUD (ShowcaseActions, ShowcaseHud, Showcase.LedSize), the
# two content fields (AiSection) and the input (SquadCommand.Dismiss, Led), UnitSpawn's squad number and the default
# IMoveOrders.TryStandAt.
# Filters: the Rc21 test classes (Rc21LedRules, Rc21LedSquad, Rc21LedState, Rc21LedKeys, three tests of Rc21LedGuards);
# the crowd entries add the older crowd tests (Wp21, Mt026, Mt153).
# Not listed: the recruit salt and Order => 1 (any value works the same); Upkeep's "not alive" skip (Drop has just removed
# such members on the same tick); Formation's check that the lattice is complete rings (always true up to six rings); the
# missing-key branch and the catch of ShowcaseActions.Led (a world with a led squad always has a player; without the catch
# a refused point only throws); the checks in Step that the player entity exists (a removed player cannot be made in a
# test); the floor switch of TryFloor in the adapter's TryStandAt (no point found that can be stood on without a walkable
# plate); Unity code (no Unity here).
