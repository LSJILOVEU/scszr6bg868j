# PROJ-1: projectiles (speed, flight, landing, pool bound, state). Filter: the PROJ-1 tests only; the legacy locks
# and every world without a projectile weapon are checked by the full suite.
# Not listed (equivalent or caught only by the full suite):
# - action ordinal 2 -> 0 or 1: a unit carries one weapon, so a projectile key never meets a shot or swing key of
#   the same unit and launch tick; kept as a guard, not testable by behaviour.
# - registering the system without a projectile weapon: the constructor refuses such a pack, so every built world
#   throws (the full suite).
# - the load's 'weapon is a projectile weapon' check: an instant weapon has 0 flights, so the k range check
#   (0 <= k < flights) refuses it as well; kept for a clearer refusal.
# - an instant weapon of a mixed pack taking the projectile path throws (zero step), never a wrong landing;
#   InstantWeaponInAMixedPackStaysInstant shows the instant weapon stays instant.
# - removal reordering the pool: the compaction keeps order by construction; RollsFollowTheFiringOrder and the
#   save order check (BadSavesAreRefused) cover the observable order.
