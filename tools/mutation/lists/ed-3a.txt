# MapTerrainMath.cs) and the facade (Presentation/Maps/MapDocument.Terrain.cs). Filter: the ED-3 tests.
# Not listed (equivalent): the road vertex backward pass (after the forward pass every pair already holds, so it never
# changes a value); the step-7 axis and range checks (steps 3, 4 and 6 already ensure them; they guard only); T <= 0
# versus T < 0 at a segment start (at T = 0 both formulas give the same distance and the same band weight); the order
# of AddSurfaceName calls (the table is sorted either way).
