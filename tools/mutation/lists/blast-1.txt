# BLAST-1: blasts (content, falloff, walls, queue, state, limits, scripted command). Filter: the BLAST-1 tests and the PROJ-1
# limit tests; worlds without blasts are checked by the full suite (digests, limits, goldens).
# Not listed (equivalent or caught only by the full suite):
# - DamageAt's 'distance >= OuterRaw' to '>': at the outer radius the formula gives 0 anyway and 0 issues nothing.
# - DamageAt's 'distance <= InnerRaw' to '<': at the inner radius the formula gives the full damage.
# - registering the blast system without blasts (CombatFeature): the BlastSystem constructor refuses such a pack, so every
#   world throws (the full suite).
# - dropping the StableId dedup in Detonate: the grid query already returns each body once (it marks the bodies it visited),
#   so a unit on a cell corner is hit once either way (B4 checks that).
# - the digest section written without blasts: the section reads the rules object, which is null then (it would throw).
