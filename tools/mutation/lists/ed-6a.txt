# ED-6a: entry facade (Presentation/Maps/MapEntrySteps.cs, MapDocument.Entries.cs).
# Filter: the ED-6a tests.
# Not listed (equivalent through the facade): a copy carrying src (MapEdit.Add drops it); WithEntryEdits applied without
# Batch (Edited discards the editor on a refusal either way, as in ED-1); a step reading the document from before the batch
# (steps only see MapEdit.Current, locked by ed1-current-stale; covered by Ed6aBatchTests fixed sequences); the cell and
# millimetre overflow guards (a wrapped value is off the map, so MapEdit refuses it with the same exception type); the
# formation spacing (WorldBuilder, not this package); the version after the last plate goes (MapDesc rule, ML-4 lists).
