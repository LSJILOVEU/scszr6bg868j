# AI-P5b: squad tempers (rash, normal, steady, shifted by losses), regrouping (the saved marks, the way back to a
# point of the team's own), the wrapped engage part, the seven new ai.squad* content fields and what the view is told.
#
# Left out, with the reason:
# - reading the mood in SquadEngage.Decide without `squads.tempered`: with no tempers all four numbers are 0, so the
#   mood is normal for every squad and the inner part is asked either way.
# - dropping `marks.Clear()` in LoadState or `marks.Remove` in Dissolve: the next `marks.Add` of the same leader ends
#   in an exception, which the tool reports as invalid, not as killed.
# - reading the marks without `regrouping` (RegroupOf, SquadEngage.Decide): the list is empty in such a battle, so
#   the read ends in an exception as well.
# - the unit's own layer in TryRally: squads are refused on a map with floor plates, so there is one layer.
