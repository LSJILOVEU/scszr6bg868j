#  - "derive does not leave out seams": a LinkDerive (TRV-2) branch, listed there as trv2-seam-ignored; here the table

#  - "a link from a node to itself": no separate check; the one-layer neighbour check (dx = dz = 0) refuses it

#  - WithLinks sharing the source's tables instead of copying: nothing writes them after construction.
